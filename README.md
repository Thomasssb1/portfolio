# Thomas Beer portfolio

Run the site locally with:

```sh
npm run dev
```

Open <http://localhost:8788>. The Web Components load their HTML and CSS files over HTTP, so opening `frontend/index.html` directly will only show their fallback text.

Avatar Outfit Shop media filenames, export sizes, and Play links are documented in [`frontend/assets/avatar-outfit-shop/README.md`](frontend/assets/avatar-outfit-shop/README.md).
